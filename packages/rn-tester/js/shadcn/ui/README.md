# shadcn/ui, vendored

The components in this directory are copied unmodified from shadcn/ui's "default" style registry (https://ui.shadcn.com, MIT), Tailwind v3 era, as of 2026-08-13. They import `@radix-ui/*`, `@/lib/utils`, `class-variance-authority` and `lucide-react` by their upstream names; Metro and Jest resolve those to the fork's implementations under `js/astryx/radix` and `js/shadcn/lib`.
