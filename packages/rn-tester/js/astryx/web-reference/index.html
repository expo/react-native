Does <ul> have padding?

Yes — every desktop browser's UA stylesheet sets padding-inline-start: 40px on ul and ol, and that gutter is what an outside marker hangs in. The red frame is the list's own box: the bullets sit inside it, the text starts 40px in.

  • tokens resolve through var() chains
  • elements keep their own tagName
  • a deliberately long item, so it wraps: the continuation lines start at the text edge rather than under the marker, which is the hanging indent outside positioning exists to produce

list-style-position

outside is the initial value: the marker is not part of the content box, so wrapped lines hang past it. inside makes it part of the content, so they align under it.

  • outside — a long item that wraps so the hanging indent is visible
  • inside — a long item that wraps so the difference is visible
